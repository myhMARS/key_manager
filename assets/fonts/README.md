# Fonts for Android Build

Place the following font files in this directory before building the APK:

1. **NotoSansSC-Regular.ttf** - Chinese text support
2. **NotoSansSC-Bold.ttf** - Chinese bold text
3. **NotoSansSymbols2-Regular.ttf** - Symbol/emoji support (✓, ✗, 🔑, 💰, etc.)

## Download

All fonts are available from Google Fonts:

- Noto Sans SC: https://fonts.google.com/noto/specimen/Noto+Sans+SC
- Noto Sans Symbols 2: https://fonts.google.com/noto/specimen/Noto+Sans+Symbols+2

Download the font families and extract the `.ttf` files into this directory.
